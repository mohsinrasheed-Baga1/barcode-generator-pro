------------------------------------------------------------
 1. انسٹالیشن / INSTALLATION (Windows)
------------------------------------------------------------

  طریقہ 1 — تیار شدہ انسٹالر استعمال کریں (تجویز کردہ):
  -----------------------------------------------------
    1. dist\BarcodeGeneratorPro_Setup.exe ڈبل کلک کریں
    2. Wizard کے ہدایات پر عمل کریں
    3. ڈیسک ٹاپ یا Start Menu سے شارٹ کٹ استعمال کریں

  طریقہ 2 — خود EXE بنا کر:
  -----------------------
    1. پہلے Python 3.10+ انسٹال کریں (https://python.org)
       (انسٹالیشن کے دوران "Add Python to PATH" ضرور چیک کریں)
    2. Inno Setup 6 ڈاؤن لوڈ اور انسٹال کریں
       (https://jrsoftware.org/isdl.php)
    3. اس فولڈر میں Command Prompt کھولیں
    4. build.bat چلائیں
       > build.bat
    5. تیار شدہ انسٹالر dist\BarcodeGeneratorPro_Setup.exe میں ہوگا

------------------------------------------------------------
 2. استعمال / USAGE
------------------------------------------------------------

  ➤ سادہ طریقہ (Single Sticker):
    1. سائیڈ پینل میں تمام معلومات درج کریں:
       - Company Name (کمپنی نام)
       - Product Name (پروڈکٹ نام — اختیاری)
       - Product Code (پروڈکٹ کوڈ)
       - Barcode (12 ہندسے — 13واں خودکار)
       - Mfg Date (مینوفیکچرنگ ڈیٹ)
       - Exp Date (ایکسپائری ڈیٹ)
       - Mobile (موبائل نمبر)
    2. Quantity میں تعداد لکھیں
    3. "Add to Sheet" بٹن دبائیں
    4. "Print" یا "Preview" بٹن دبائیں

  ➤ بلک CSV امپورٹ:
    1. "Save Template" بٹن دبائیں — ایک sample CSV فائل بن جائے گی
    2. اپنے ڈیٹا کو اس CSV میں جمع کریں (Excel میں کھول کر)
    3. "Import CSV" بٹن دبائیں اور CSV فائل منتخب کریں
    4. تمام بارکوڈ شیٹ میں آ جائیں گے

  ➤ سائز تبدیل کرنا:
    1. "Settings" بٹن دبائیں
    2. "Sheet Layout" ٹیب میں:
       - Quick Presets سے کوئی بھی معیاری سائز چنیں
       - یا خود ساخت (Custom) سائز درج کریں: پیپر، اسٹیکر، مارجن،
         گیپ — کالم اور قطاریں خود کار طور پر حساب ہو جائیں گے
    3. "Save" دبائیں

  ➤ فونٹس بدلنا:
    Settings > Fonts ٹیب میں ہر فیلڈ کا فونٹ سائز تبدیل کر سکتے ہیں

  ➤ ہسٹری دیکھنا / دوبارہ استعمال:
    1. "History" بٹن دبائیں
    2. تلاش (Search) باکس میں کوئی بھی لفظ لکھیں
    3. کسی ریکارڈ کو ڈبل کلک کریں — اس کی معلومات خودبخود
       مین فارم میں آ جائیں گی

------------------------------------------------------------
 3. CSV فائل کی فارمیٹ
------------------------------------------------------------

  Header (پہلی سطر) یہ ہونا چاہیے (چھوٹے یا بڑے حروف دونوں OK):
    company_name,product_name,product_code,barcode,
                  mfg_date,exp_date,mobile

  barcodes کالم لازمی ہے۔ باقی تمام کالم اختیاری ہیں۔

  mfg_date اور exp_date کی فارمیٹ: YYYY-MM-DD (جیسے 2025-01-15)

  barcode کالم میں 12 یا 13 ہندسے درج کریں۔ آخری (13واں)
  ہندسہ نکلنے والا نہیں — سافٹ ویئر خود اضافہ کر دے گا۔

------------------------------------------------------------
 4. پرنٹنگ کی تجاویز
------------------------------------------------------------

  • پرنٹر سیٹنگز میں:
      - Paper size: A4
      - Margins: None (0)
      - Scaling: 100% (no "fit to page")
  • استعمال کرنے سے پہلے "Preview" سے پوری طرح پرنٹ ہونے کا
    تصدیق کریں
  • پہلے تجربے کے طور پر ایک کاپی پرنٹ کر کے بارکوڈ کو اسکینر
    سے پڑھ کر تصدیق کریں

------------------------------------------------------------
 5. لیبل پرنٹر موڈ (بارکوڈ پرنٹر)
------------------------------------------------------------

  اگر آپ کے پاس لیبل پرنٹر ہے (جیسے Zebra, TSC, Xprinter,
  Godex, Rongta وغیرہ) — جس میں چھوٹے لیبلز ایک وقت میں
  ایک print ہوتے ہیں — تو یہ سافٹ ویئر اسے بھی پوری طرح
  سپورٹ کرتا ہے۔

  ترتیب:
    1. "Settings" بٹن دبائیں
    2. "Sheet Layout / شیٹ سائز" ٹیب میں اوپر "Print Mode" دیکھیں
    3. ان دو آپشنز میں سے منتخب کریں:
       📄 Sheet Printer (A4 paper — multi-sticker per sheet)
       🖨 Label Printer (direct — one label at a time)
    4. "Label Printer" منتخب کریں
    5. Quick presets میں سے اپنے لیبل کا سائز چنیں:
       - 50x30 mm (قیمت کے لیے عام)
       - 40x30 mm (چھوٹے بارکوڈ)
       - 60x40 mm (پروڈکٹ لیبل)
       - 70x40 mm (بڑے پروڈکٹ)
       - 100x50 mm (لوجسٹک)
       یا "Custom" سائز درج کریں (اپنے لیبل کے مطابق)
    6. "Save" دبائیں

  پرنٹ کرنے کے لیے:
    1. مین ونڈو میں آئٹمز add کریں (پہلے کی طرح)
    2. "Print" بٹن دبائیں
    3. پرنٹ ڈائیلاگ میں اپنے لیبل پرنٹر کو منتخب کریں
       (Zebra / TSC / Xprinter / Godex وغیرہ)
       ⚠️ A4 پرنٹر کو منتخب نہ کریں!
    4. پرنٹر driver میں label size settings کو بھی اسی سائز
       پر set کریں جو آپ نے سافٹ ویئر میں منتخب کیا ہے
       (مثلاً 50x30mm)
    5. "Print" دبائیں — ہر آئٹم ایک علیحدہ لیبل پر پرنٹ ہوگا

  ⚠️ اہم نکات:
    • پرنٹر driver کا label size = سافٹ ویئر کا label size
      (ورنہ پرنٹ غلط سائز میں نکلے گا)
    • Copies count: آپ کے queue میں ہر آئٹم × copies = کل labels
      مثلاً 3 آئٹمز × 2 copies = 6 labels print ہوں گے
    • لیبل پرنٹر کی "page size" خود کار طور پر label size ہوتی ہے

------------------------------------------------------------
 6. ڈیٹا کی محفوظگی
------------------------------------------------------------

  ڈیٹا SQLite ڈیٹابیس میں محفوظ ہوتا ہے جو اس جگہ ہے:
    %APPDATA%\BarcodeGenerator\barcodes.db

  سیٹنگز بھی اس فولڈر میں محفوظ ہوتی ہیں۔

  انسٹالیشن اور ان انسٹالیشن پر ڈیٹا محفوظ رہتا ہے۔ مکمل صاف
  کرنے کے لیے Settings > Data ٹیب میں "Clear all history" استعمال
  کریں۔

------------------------------------------------------------
 6. پریشانی؟
